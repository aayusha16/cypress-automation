# JPetStore Cypress Automation

This project contains automated tests for the JPetStore web application using Cypress and JavaScript.

## Test Coverage

The following functionalities are covered:

* Login
* Registration
* Search
* Add to Cart
* Checkout

## Tools Used

* Cypress
* JavaScript
* Node.js
* Git and GitHub

## How to Run

Install the project dependencies:

```bash
npm install
```

Open Cypress:

```bash
npx cypress open
```

To run all tests:

```bash
npx cypress run
```

## Purpose

This project was created to practice software testing and end to end test automation using Cypress.
